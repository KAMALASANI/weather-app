# Weather App 🌤️

A simple and responsive Weather App that allows users to search for the current weather information of any city using the OpenWeather API.

## Features

- Search weather by city name
- Displays current temperature in Celsius
- Displays current weather condition
- Simple and user-friendly interface
- Real-time weather data using OpenWeather API

## Technologies Used

- HTML
- CSS
- JavaScript
- OpenWeather API

## How It Works

1. Enter a city name in the search box.
2. Click the "Get Temperature" button.
3. The application fetches weather data from the OpenWeather API.
4. The temperature and weather condition are displayed.
